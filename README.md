# Dolor Róza - Clinical Psychology Website

Professional online presence for Dolor Róza, a licensed clinical psychologist practicing in Hungary.

## Overview

This static website serves as a digital showcase for therapy services, enabling prospective clients to discover the therapist's background and reach out for consultations. Built entirely in Hungarian to serve the local Hungarian-speaking community.

## Site Structure

### Main Pages

1. **index.html** - Homepage
   - Hero banner featuring branded imagery
   - Welcoming introduction
   - Overview of topics covered
   - Therapy journey breakdown (4 steps)
   - Contact information

2. **rolam.html** - Professional Profile
   - Biography and headshot
   - Academic credentials and certifications
   - Therapeutic philosophy and methods

3. **arak.html** - Fee Structure
   - Per-session pricing
   - Bundled session packages
   - Virtual session rates
   - Billing policies and payment methods
   - Financial assistance resources

## Tech Stack

### Core Technologies
- **HTML5** - Accessible semantic markup
- **CSS3** - Modern custom styles including:
  - Flexbox-based layouts
  - Smooth page scrolling
  - Mobile-responsive breakpoints
  - Interactive hover states and animations
  - Styled numbered lists for therapy steps

### UI Framework
- **Bulma CSS** (v0.9.4) - Loaded via CDN
  - Adaptive grid layouts
  - Ready-made UI elements (navigation, cards, buttons, columns)
  - Contemporary styling

### Scripting
- **Vanilla JavaScript** - Lightweight interactivity:
  - Hamburger menu toggling for mobile navigation
  - Anchor-based smooth scrolling

### Source Control
- **Git** - Version history management

## Design Highlights

- **Polished Aesthetic**: Contemporary, clean layout built on Bulma with tailored enhancements
- **Device-Agnostic**: Mobile-first design philosophy with responsive queries for all viewports
- **Inclusive Access**: Semantic structure, ARIA attributes, intuitive navigation flow
- **Open Pricing**: Comprehensive rate information with bundled options
- **Intuitive Navigation**: Consistent menu system across all pages
- **Mobile Enhancements**:
  - Collapsible hamburger navigation
  - Optimized background images for faster mobile loading
  - Adaptive text sizing and layout spacing
